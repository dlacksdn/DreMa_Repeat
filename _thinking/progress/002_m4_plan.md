## 0. 새로 알아낸 것 2가지

### ① 원본 시범의 **RLBench 학습용 사진이 없다**

```python
low_dim_obs.pkl  →  Demo, 90스텝
    front_rgb    = None      ← 사진 없음
    front_depth  = None
    gripper_pose = (7,)      ← 좌표만 있음
images/          →  1280x720 사진 200장 (3D 복원용. 학습용 128x128 아님)
```

→ 논문의 **"PerAct (Original data) = 48.4 %"** 를 그대로 재현할 수 없다.
DreMa 샘플은 **3D 복원용**으로 만들어져 RLBench 관측이 애초에 빠져 있다.

### ② 그런데 **난수 씨앗이 저장돼 있다**

```python
Demo.random_seed = ('MT19937', array([3101460856, ...], dtype=uint32), 51, 0, 0.0)
variation_number = 0        # green 목표
```

RLBench 는 물체 배치를 `numpy` 난수로 정한다. 난수 발생기 **상태 전체**가 있으므로
되돌려 놓으면 **완전히 같은 장면**을 재현할 수 있다 → **3D 복원 불필요.**
필요한 것은 그 장면을 다시 띄워 **128×128 사진만 렌더**하는 것뿐이다.

> 앞서 "3D 복원부터 다시 해야 한다"고 적었던 것은 **틀렸다.** 새 장면을 만든다고 가정했기 때문이다.

## 2. 미리 확정한 판단 규칙 5개

새 세션에서 사람 판단 없이 진행하기 위해 못박은 것들이다.

### ① 씨앗 검증 합격 기준
```
재현한 gripper_pose 90스텝  vs  기존 low_dim_obs.pkl
   최대 오차 < 1 mm  →  일치. B안 (논문 조건)
   그 외             →  불일치. A안 (가우시안 재생본)
```
중간 지대 없음. **애매하면 A안.** 불확실한 데이터로 논문 비교를 주장하지 않는다.

### ② 결과별 학습 데이터

| | 모델 A (대조군) | 모델 B (실험군) |
|---|---|---|
| **B안 성공** | RLBench 원본 1개 | RLBench 원본 1개 + 증강 17 |
| **A안 (실패)** | 가우시안 재생본 1개 | 가우시안 재생본 1개 + 증강 17 |

증강 17개는 `data/aug_tau015_paper/` 로 공통.

### ③ 학습 설정 — 논문 부록 L 그대로
```
method=PERACT_BC · batch 4 · 100k 반복 · 5k마다 체크포인트
카메라 front,left_shoulder,right_shoulder · 128x128
```
**100k 를 줄이지 않는다.** 느려도 5k마다 저장되니 중간에 끊어도 버려지지 않는다.

### ④ 순차 실행
모델 A 끝 → 모델 B. 동시 실행 금지(서로 느려지고 공용 머신 부담).

### ⑤ 실패 시 중단
각 단계 실패하면 거기서 깨끗이 종료하고 로그를 남긴다. **잘못된 데이터로 학습을 시작하지 않는다.**

## 3. 왜 "모델 2개"인가

```
모델 A (대조군) : 시범 1개만            → 성공률 ?%
모델 B (실험군) : 시범 1개 + 증강 17개  → 성공률 ?%
                      ↓
        두 수치를 비교해야 증강의 효과를 말할 수 있다
```
대조군이 없으면 "62%" 라는 숫자가 나와도 증강 덕분인지 알 수 없다.

**논문 목표치** (Table 1, slide_block): 원본만 **48.4** → 전부 **62.0**
단 논문은 데이터 65개, 우리는 18개(**28 %**) → **낮게 나오는 것이 정상.**
볼 것은 절대값이 아니라 **"원본만 < 전부" 방향**이다.

## 4. 헷갈리기 쉬운 % 정리

| 종류 | 값 | 무엇 |
|---|---|---|
| **성공률** | 48.4 / 54.4 / 62.0 / 26.0 | 로봇이 과제를 해낸 비율. **M5 에서 잴 것** |
| **채택률** | 논문 41~61 % · 우리 49 % | 증강 중 τ 검수를 통과한 비율. **이미 끝난 이야기** |
| 데이터 비 | 28 % | 우리 18개 / 논문 65개 |

서로 다른 것을 센다. 채택률이 높다고 성공률이 오르지 않는다(τ=0.035 는 채택률 92%지만 품질이 나쁜 시범이 섞인다).
